# Personalized Webpage

An interactive, responsive webpage that takes user input (Name and Age), stores it in browser local storage, and dynamically displays personalized content including age calculations, age-restricts features, and displays motivational messages.

## Features

- **Local Storage Persistence:** Remembers user data even after refreshing or re-opening the browser.
- **Conditional Age Logic:** Checks if the user is 18 or older and updates permissions accordingly.
- **Dynamic Age Calculations:** Converts user age into total months using JavaScript functions.
- **Template Literals:** Displays customized greetings seamlessly.
- **Loop Implementation:** Renders motivational messages dynamically using standard `for` loops.
- **Responsive CSS:** Formatted and styled for desktop and mobile viewing.

## Getting Started

### Prerequisites

You only need a modern web browser (e.g., Chrome, Edge, Firefox, Safari).

### Local Setup

1. Clone this repository or download the source code files.
2. Ensure `index.html`, `style.css`, and `script.js` are in the same folder.
3. Open `index.html` directly in your browser.
